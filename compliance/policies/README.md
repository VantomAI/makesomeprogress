# Make Some Progress Compliance Policies

These lightweight policy documents support Plaid compliance attestations for Make Some Progress, a small single-owner budgeting application.

The application is local-first. Bank connectivity is optional, read-only, authenticated through Supabase, and implemented through Supabase Edge Functions. Plaid access tokens are not stored in the browser or GitHub repository.
